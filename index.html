OnTheWay - Route-Aware Pickup and Reservation Platform

A Spring Boot and React/TypeScript platform for route-aware pre-ordering across customer, merchant, and admin roles. Its ETA-synchronization engine uses a pluggable RouteProvider to time preparation so an order is ready when the customer arrives.

The current build includes REST and GraphQL APIs, JWT/BCrypt authorization, order and payment audit trails, Stripe/Razorpay adapters, WebSockets, Kafka events, Elasticsearch search, Flyway migrations, Docker, Kubernetes, CI, 70+ tests, and a simulated 1,000-user load test.

Local-first AI product

Carivyo-AI - Local-First LLM Job-Search and Application Agent

A privacy-first Node.js web app for resume-led job discovery and application workflows. It parses text, PDF, and DOCX resumes, supports multiple resume profiles, scans five ATS providers plus official HTML career pages, verifies freshness, and produces evidence-backed fit, gaps, risks, and facts-only application materials.

Django ML application

WaterNet - Water Potability Classification Platform

A modernized Django application that classifies water samples from 9 chemistry inputs. The current code evaluates six scikit-learn models and serves a cached voting ensemble of logistic regression, random forest, and gradient boosting with deterministic train/test evaluation.

It includes hashed-password authentication with legacy upgrades, validated sample submission, SQLite by default with optional MySQL, traceable scores and predictions, CSV export, and tests for auth, model, prediction, provider ratios, training output, and export.
